# Development guide

## Toolchains

- Node.js 22.12 or newer
- Go matching `source/server/go.mod`
- JDK 21 and Android SDK 36 for Android work
- Docker with Buildx for container release validation

Install JavaScript dependencies from `source`:

```bash
npm ci
```

## JavaScript workspace

```bash
npm test
npm run typecheck
npm run lint
npm run format:check
npm run build
```

The normal web build includes the PWA manifest and service worker. The Android
mode disables service-worker generation so it cannot interfere with the native
Capacitor bridge:

```bash
npm run build:android --workspace @lastdone/web
```

## Go server

```bash
cd source/server
go test ./...
go run . serve --http=127.0.0.1:8090
```

For local development, build the web application and place its output in the
server public directory, or run Vite separately and direct API requests to the
server.

## Cross-language behavior

Schedule and status fixtures live in `source/packages/contracts`. Both the
TypeScript domain package and Go server tests consume the same semantics for
calendar-month clamping, leap years, fixed occurrences, and state ordering.

## Generated and private files

Do not commit:

- `node_modules`, `dist`, coverage, test results, or Gradle build output;
- PocketBase runtime data in `source/server/pb_data`;
- copied Capacitor web assets;
- `.env` files, JKS/keystore files, or signing passwords.

The checked-in Android Gradle project is source. The assets copied into
`android/app/src/main/assets/public` are generated by `cap sync` and ignored.
